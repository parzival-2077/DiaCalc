# DiaCalc

**DiaCalc** — Android-приложение для расчёта количества углеводов и хлебных единиц (ХЕ) в продуктах питания.

Приложение позволяет быстро рассчитать содержание углеводов в порции, количество хлебных единиц и дополнительное значение на основе пользовательского коэффициента.

Интерфейс разработан с использованием **Jetpack Compose** и **Material 3** с поддержкой динамических цветов Android.

## Возможности

- **Расчёт углеводов** — определение количества углеводов в порции на основе содержания углеводов на 100 г продукта.
- **Расчёт хлебных единиц** — вычисление ХЕ с возможностью изменения количества граммов углеводов на одну хлебную единицу.
- **Пользовательский коэффициент** — дополнительный расчёт на основе заданного множителя.
- **Автоматическое обновление результатов** — пересчёт при изменении входных данных без отдельной кнопки.
- **Удобный ввод** — цифровая клавиатура с переходом между полями.
- **Material 3** — современный интерфейс с поддержкой светлой и тёмной темы.

## Технологии

- **Kotlin** — основной язык разработки.
- **Jetpack Compose** — декларативный пользовательский интерфейс.
- **Material 3** — компоненты и оформление интерфейса.
- **Android Jetpack ViewModel** — управление состоянием экрана.
- **Kotlin Coroutines и StateFlow** — реактивное обновление данных.
- **MVVM** — разделение пользовательского интерфейса и логики приложения.

### Domain

Содержит вычислительную логику приложения, независимую от пользовательского интерфейса.

- `Calculator.kt` — выполнение расчётов.
- `CalculatorResult.kt` — модель результатов вычисления.

### Presentation

Отвечает за отображение данных и взаимодействие с пользователем.

- `CalculatorScreen.kt` — основной экран калькулятора.
- `CalculatorViewModel.kt` — обработка ввода и обновление результатов.
- `CalculatorUIState.kt` — состояние экрана.
- `CalculatorTextField.kt` — переиспользуемый компонент числового ввода.
- `ResultCard.kt` — компонент отображения результатов.

## Принцип работы

Пользователь вводит четыре параметра:

1. **Углеводы на 100 г** — содержание углеводов в продукте.
2. **Вес порции** — масса продукта в граммах.
3. **Грамм на 1 ХЕ** — количество углеводов, соответствующее одной хлебной единице.
4. **Коэффициент** — пользовательский множитель для дополнительного расчёта.

### Формулы

**Количество углеводов:**

```text
Углеводы = (Углеводы на 100 г × Вес порции) / 100
```

**Количество хлебных единиц:**

```text
ХЕ = Углеводы / Грамм на 1 ХЕ
```

**Расчёт по коэффициенту:**

```text
Результат = ХЕ × Коэффициент
```

### Пример

Исходные данные:

| Параметр | Значение |
|---|---|
| Углеводы на 100 г | 45 г |
| Вес порции | 150 г |
| Грамм на 1 ХЕ | 12 г |
| Коэффициент | 1,5 |

Результаты:

| Показатель | Значение |
|---|---|
| Углеводы | 67,5 г |
| Хлебные единицы | 5,63 ХЕ |
| Расчёт по коэффициенту | 8,44 |

Результаты в интерфейсе отображаются с округлением до двух знаков после запятой.

## Установка и запуск

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/USERNAME/diacalc.git
   ```

2. Откройте проект в **Android Studio**.
3. Дождитесь завершения синхронизации Gradle.
4. Подключите Android-устройство или запустите эмулятор.
5. Нажмите **Run** для сборки и запуска приложения.

Замените `USERNAME` на владельца репозитория.
